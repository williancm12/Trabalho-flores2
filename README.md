## Como executar

Requisito: PHP 8.0 ou superior (o PHP do XAMPP já atende, inclusive a extensão `mbstring`).

Abra a pasta do projeto no VSCode, abra o terminal integrado (`Ctrl + '`) e execute o exercício desejado:

```bash
php exercicio01.php
```

Os exercícios **07, 09, 10, 12, 13 e 14** são interativos (leem o que o usuário digita), por isso devem ser executados pelo terminal, e não pelo navegador.
